# 🚀 ACM Satellite Simulation System

## 📌 Overview

This project is a containerized simulation system built using Python and Docker.
It models satellite behavior and provides an interface to interact with the simulation.

---

## 🛠️ Tech Stack

* Backend: Python (FastAPI)
* Frontend: HTML
* Containerization: Docker

---

## 📂 Project Structure

```
ACM/
├── app/
│   ├── api/
│   ├── core/
│   ├── models/
│   └── main.py
├── frontend/
│   └── index.html
├── Dockerfile
├── requirements.txt
└── README.md
```

## ▶️ How to Run the Project

### 1. Clone the repository

```
git clone https://github.com/yourusername/repo-name.git
cd repo-name
```

### 2. Build the Docker image

```
docker build -t satellite-app .
```

### 3. Run the container

```
docker run -p 8000:8000 satellite-app
```
